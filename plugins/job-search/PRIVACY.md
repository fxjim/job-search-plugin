# Privacy policy — Job Search by Pixel & Cog

The package has no server, telemetry, analytics, account system, credential store or network-sending implementation. The optional helper reads/writes local JSON and text. The host assistant still processes conversation content under its own account, storage and data controls. Using a connected research tool may disclose a query or content to that service; inspect its permissions and policies. No blanket zero-transmission or encryption claim is made.

The user chooses and confirms a private data directory outside the installed skill before saving. Expected records are preferences, evidence references, source-check metadata, posting assessments, exact draft materials, review hashes and duplicate history. Keep resumes, immigration/eligibility details and personal contact data to the minimum needed. Do not store passwords, access tokens, government-ID scans or unrelated mail. Unknown eligibility remains unknown.

The helper creates ledgers with owner-only file mode 0600 and atomic writes on supported POSIX systems. This is not encryption, backup protection or a tamper-proof audit. The agent must use appropriate local permissions for other files and check the actual host's save result. No automatic cross-chat memory, sync or backup is promised.

To remove local records, delete the exact data directory you selected after retaining anything you want. Removing the skill alone leaves that data and chat history intact. Remove backups, exports or host chat history separately through their own controls if desired. Connected account revocation uses the provider/host's supported controls; this package has no grants to revoke itself.

For support, share only a redacted error and reproducible steps. Never attach your full ledger, resume, inbox, raw chat log, tokens or personal path unless an authorized support workflow specifically needs a reviewed subset. There is no product-operated upload endpoint.

Effective October 9, 2026. Public policy: https://github.com/fxjim/job-search-plugin/blob/v0.3.3-pilot.3/plugins/job-search/PRIVACY.md. Privacy questions may be raised through [GitHub Issues](https://github.com/fxjim/job-search-plugin/issues) using no personal records. GitHub receives public issue content under its own policies; never post candidate data there. Pixel & Cog operates no server or collection endpoint for this package.
