# Support and feedback

Publisher: **Pixel & Cog**. Public support contact: [GitHub Issues](https://github.com/fxjim/job-search-plugin/issues). File a [new issue](https://github.com/fxjim/job-search-plugin/issues/new) with a redacted error and a minimal fictional reproduction. No response-time guarantee is made. Issues are public: never include resumes, candidate profiles, application history, eligibility documents, raw chats, inbox contents, credentials or personal filesystem paths. There is no private product support upload endpoint.

Include package version, OS/host version, installation route, whether the host actually supplied Job Search, expected versus observed result, exact redacted error and synthetic steps. Say whether setup, research, preparation or review failed. Installation, host loading and a submitted application are different observations.

Stop repeated calls when access is denied, a source is blocked or a prior action may still be running. Keep the last stage and error; do not bypass permissions or change unrelated settings. Pasted public posting text is an alternative when tools are unavailable, with live status labeled unverified. This release performs no uploads or applications.
