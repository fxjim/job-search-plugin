# Manual application handoff

This preparation-only pilot does not fill employer forms, upload, send email, submit applications/proposals, spend money or record application authority. If the user requests execution, explain this scope and finish all authorized research/draft work that remains useful.

Give the user the current employer-published application URL or address, the exact reviewed text/materials, outstanding eligibility or attestation questions, and any access block. Do not invent an address or promise delivery. The user must inspect the actual form, its required formats and fields before applying. An employer-offered resume text field is an option only when observed; do not assume it exists or that a document matches accepted formats.

No file-picker calls are needed. For a previously hanging call from another workflow, stop new calls until its outcome/cancellation is established. Preserve the last evidence and ask for supported manual handling. Never bypass permission, CAPTCHA or access restrictions. A requested timeout is not evidence of enforced cancellation.

Review confirms wording only. The user may act manually outside this pilot. Use [outcome rules](applications.md) to describe any later evidence honestly, without inventing a successful submission or writing a pilot receipt.
